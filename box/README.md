# Bitrone Box — экран и световая полоса на подставке

Плата RP2040-Zero в подставке получает питание и данные **по одному USB-кабелю** от мини-ПК.
Служба `bitrone-box-status` на мини-ПК смотрит в папку копий (rest-server) и каждые 10 с
отправляет на плату, что показать: когда пришла последняя копия, полная копия, диск,
катапульта. Ключ шифрования клиента для этого не нужен — служба видит только время файлов.

```
Мини-ПК ──USB──▶ RP2040-Zero ──I²C──▶ OLED 1.3" 128×64
                      └──────1 провод──▶ 10 × WS2812 (полоса)
```

## Детали (AliExpress)

| Деталь | Что искать | ~Цена |
|---|---|---|
| Плата | `Waveshare RP2040-Zero` | 4–5 $ |
| Экран | `1.3 inch OLED SH1106 I2C 128x64` (4 контакта) | 4–6 $ |
| Полоса | `WS2812B 144 LED/m` — отрезать 10 светодиодов | 3 $ |
| Резистор | 330 Ом (на линию данных полосы) | — |
| Кнопка (по желанию) | любая тактовая 6×6 мм | — |
| Кабель | USB-C ↔ USB-A, 30–50 см | 2 $ |

Можно взять экран 0.96" SSD1306 — тогда в `firmware/main.py` поставить `OLED_DRIVER = "ssd1306"`.

## Пайка

| Откуда (RP2040-Zero) | Куда |
|---|---|
| `3V3` | OLED `VCC` |
| `GND` | OLED `GND`, полоса `GND`, кнопка |
| `GP4` | OLED `SDA` |
| `GP5` | OLED `SCL` |
| `5V` | полоса `5V` |
| `GP6` → резистор 330 Ом | полоса `DIN` (вход, по стрелке на ленте) |
| `GP7` | кнопка (второй контакт кнопки — на `GND`) |

Яркость полосы ограничена в прошивке (`LED_MAX = 60`), ток с USB — до ~150 мА.

## Прошивка платы (один раз)

1. Скачать MicroPython для **Raspberry Pi Pico** (файл `.uf2`) с micropython.org/download/RPI_PICO —
   подходит и для RP2040-Zero.
2. Зажать кнопку **BOOT** на плате, подключить USB к компьютеру, отпустить —
   появится диск `RPI-RP2`. Перетащить на него `.uf2`. Плата перезагрузится.
3. Скопировать файлы прошивки (с любого компьютера с Python):
   ```bash
   pip install mpremote
   mpremote cp box/firmware/oled.py :oled.py
   mpremote cp box/firmware/main.py :main.py
   mpremote reset
   ```
   Или через программу Thonny: открыть файл → «Сохранить как» → «Raspberry Pi Pico».
4. После перезагрузки экран покажет «Start · Gözləyir...», полоса — синий бегущий огонь.
   Через 2 минуты без данных от ПК — «PC ? · Kompüter cavab vermir» и оранжевый.

## Служба на мини-ПК

```bash
sudo bash box/install-status.sh --user restic --device /dev/sda
sudo nano /etc/bitrone-box/box.conf      # SN, CLIENT, SOURCE (какая папка копируется)
sudo systemctl restart bitrone-box-status
sudo -u restic python3 /opt/bitrone-box/bitrone_box_status.py --once   # что уйдёт на экран
```

`--user` — пользователь, от которого работает rest-server: служба читает его папку копий.

## Что на экране

Страницы сменяются каждые 5 с:

| Страница | Пример |
|---|---|
| Последняя копия | `✓ 12 dəq` · `Son nüsxə: 14:32` · `Tam: Bazar 02:10` |
| Диск | `38%` · `Disk: 190/500 GB` · `Sağlamlıq: OK` |
| Клиент и папка | `Müştəri: INCHMARK` · `Qovluq: D:\1C\Buh` |
| Катапульта | `HÜCUM` · `KATAPULT` · `Data xilas 14:47` — экран мигает |

Цвет полосы:

| Состояние | Полоса | Когда |
|---|---|---|
| `ok` | зелёная | копия свежее `WARN_HOURS` (2 ч), полная — свежее 8 дней, диск < 85% |
| `busy` | синий бегущий огонь | идёт приём копии (в хранилище есть lock) |
| `warn` | оранжевое «дыхание» | копий нет дольше 2 ч / полная старая / диск / SMART / ПК молчит |

## Как служба понимает тип копии

По имени папки хранилища внутри `REPO_ROOT`:
`full*` — еженедельная полная, всё остальное — ежечасные изменения.

Служба также пишет `/run/bitrone-box/status.json` — локальный файл состояния (для диагностики на самой коробке). Наружу никуда не отправляется.
