# Скриншоты для гайда restic + Token2 FIDO2 (Метод A)

Положи сюда реальные скриншоты с этими именами — они автоматически появятся
в `docs/restic-token2-fido2.html` и в RU-версии:

| Файл | Что на скриншоте |
|---|---|
| `01-enroll.png` | Шаг 1 — регистрация ключа: запрос PIN + касание (`fido2-cred -M -h -v`) |
| `02-verify.png` | Шаг 3 — шифрование/расшифровка файла ключом; «bad decrypt» при неверном пароле |
| `03-restic.png` | Шаг 4 — `restic restore` через ключ: «password is correct» |

Если файла нет — слот просто скрывается (ничего не ломается). PNG или JPG, ширина ~1000–1400 px.
