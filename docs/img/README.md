# Скриншоты для гайда restic + Token2 FIDO2

Положи сюда свои реальные скриншоты с этими именами — они автоматически появятся
в `docs/restic-token2-fido2.html` (и в RU-версии, если добавить туда такие же слоты):

| Файл | Что на скриншоте |
|---|---|
| `01-enroll.png`  | регистрация ключа: запрос PIN + касание (шаг `fido2-cred -M -h -v`) |
| `02-restore.png` | `restic restore` через ключ: PIN + касание, «repository opened» |
| `03-pam.png`     | `pamtester` требует ключ (Метод B): «Please touch the device» |

Если файла нет — слот просто не показывается (ничего не ломается). Форматы: PNG или JPG.
Рекомендуется обрезать до содержимого терминала и шириной ~1000–1400 px.
