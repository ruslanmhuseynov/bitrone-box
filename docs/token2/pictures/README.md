# Скриншоты для Token2-гайда (index.html)

Как в шаблоне Token2 — картинки лежат в `pictures/` рядом с `index.html`:

| Файл | Что на скриншоте |
|---|---|
| `pic1.png` | Шаг 1 — регистрация ключа: запрос PIN + касание |
| `pic2.png` | Шаг 3 — шифрование/расшифровка файла; «bad decrypt» при неверном пароле |

PNG, ширина ~1000–1400 px. После того как положишь файлы — открой `index.html`, картинки встанут.
